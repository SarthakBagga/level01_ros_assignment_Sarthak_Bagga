4. File/location: testbed_gazebo/CMakeLists.txt, install(DIRECTORY ...).

   Root cause: Models directory omitted from installation.

7. File/location: testbed_description, testbed_bringup, testbed_gazebo/package.xml.

RUNTIME-OBSERVED DEFECTS

8. File/location: testbed_description/urdf/testbed.gazebo, ray/range/max.
   Symptom/impact: At spawn (0,5,0), every one of 30 scans had 0/300 usable returns.
   Root cause: 1.5 m range misses the observed surrounding obstacle distances.
   Change: Increased simulated maximum range to 10.0 m.
   Verification: Repeated 30-scan measurement gave 222/300 usable returns per scan,
   approximately 3.38-10 m. No localization success/failure is claimed.

9. File/location: testbed_description/urdf/testbed.gazebo, control plugin.
   Symptom/impact: Gazebo logged failure to load libgazebo_ros_control.so.
   Root cause: Referenced library is unavailable in the tested Humble environment.
   Change: Removed only this unnecessary plugin declaration.
   Verification: No plugin-load failure after removal; diff_drive_control still
   accepts /cmd_vel, publishes /odom and odom->base_footprint, and moves the robot.
   No controller conflict was observed or claimed.

10. File/location: testbed_bringup/launch/testbed_full_bringup.launch.py and
    testbed_gazebo/launch/spawn_testbed.launch.py, startup ordering.
    Symptom/impact: Intermittent gzserver SIGSEGV immediately after robot spawn;
    /clock, /odom and /scan publishers disappear when the server dies.
    Root cause: GDB located the crash in ODE dSpaceCollide2 via
    ODEMultiRayShape::UpdateRays / RaySensor::UpdateImpl during insertion.
    Concurrent insertion/ray updating is the supported timing diagnosis; the
    internal Gazebo memory fault has not been isolated to a source-code line.
    Change: Start Gazebo paused in a scoped launch group. On successful spawn
    process exit, call /unpause_physics and wait for its response. On spawn error,
    shut down. Preserve pause:=true for intentional paused inspection.
    Verification: 10/10 repeated full starts automatically unpaused and produced
    30 advancing scans plus odometry each, without crashes. Motion/TF also passed.
    No fixed sleep in launch; finite repeat testing is not a universal guarantee.

11. File/location: testbed_gazebo/launch/spawn_playground.launch.py, model path.
    Symptom/impact: Gazebo GUI logged Missing model.config for ament_index,
    colcon-core and testbed_description directories.
    Root cause: Entire description package share directory treated as model root.
    Change: Add only the supplied installed models directory to GAZEBO_MODEL_PATH;
    retain any existing model paths. World argument is unchanged.
    Verification: Playground world still loads; those model.config errors absent.

12. File/location: testbed_description/urdf/testbed.gazebo, body_color property.
    Symptom/impact: GUI logged Unable to get Material[Gazebo/Silver]; white fallback.
    Root cause: Gazebo/Silver is absent from the installed Gazebo material script.
    Change: Use the existing Gazebo/Grey material.
    Verification: Installed definition checked; missing-material warnings absent.
